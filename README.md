# 📚 Technical Writing Notes

### Technical Documentation, Scientific Typesetting & Version Control

> **Learn. Document. Collaborate. Version.**

A structured repository documenting the concepts, tools, and practical skills acquired through the **Technical Writing (TW)** course at **Malaviya National Institute of Technology (MNIT), Jaipur**.

This repository explores the fundamentals of **LaTeX, Beamer, Doxygen, Google Docs, Git, and GitHub**, focusing on effective technical communication, professional documentation, collaborative workflows, and version control.

It serves as both an **academic learning record** and a practical reference for technical documentation in software engineering.

---

## 🔗 About

Technical writing plays an essential role in software development, research, engineering, and collaborative projects.

Beyond writing technical content, it involves presenting information accurately, maintaining structured documentation, managing revisions, and communicating complex concepts clearly.

This repository brings together six essential tools used in modern technical documentation.

**The primary objectives are to:**

- Understand the principles of professional technical writing.
- Create structured scientific and technical documents.
- Design academic presentations using LaTeX Beamer.
- Generate source code documentation using Doxygen.
- Explore collaborative editing through Google Docs.
- Understand version control using Git.
- Manage repositories and collaboration through GitHub.
- Develop practical documentation workflows.

## 🚀 Topics Covered

### 📝 1. LaTeX — Scientific Document Preparation

LaTeX is a document preparation system widely used for academic papers, scientific publications, technical reports, and mathematical documentation.

**Key Concepts:**
- Introduction to LaTeX and its applications.
- Basic document structure and syntax.
- Document classes and packages.
- Text formatting and sectioning.
- Mathematical equations and expressions.
- Tables, figures, and lists.
- Cross-referencing and citations.
- Document compilation and PDF generation.

📂 **Documentation:** [LaTeX Notes](01-LaTeX/README.md)

---

### 📊 2. Beamer — Professional Presentations

Beamer is a LaTeX document class used to create structured, high-quality presentations, particularly in academic and technical environments.

**Key Concepts:**
- Introduction to Beamer.
- Creating presentation frames.
- Themes and color customization.
- Blocks and structured content.
- Lists, tables, and mathematical expressions.
- Overlays and incremental content.
- Presentation compilation.

📂 **Documentation:** [Beamer Notes](02-Beamer/README.md)

---

### ⚙️ 3. Doxygen — Source Code Documentation

Doxygen is a documentation generator that extracts structured information from source code comments and produces readable technical documentation.

**Key Concepts:**
- Introduction to Doxygen.
- Importance of source code documentation.
- Documentation comment syntax.
- Documenting functions, classes, and parameters.
- Doxygen commands and tags.
- Configuration using Doxyfile.
- Generating HTML and LaTeX documentation.
- Exploring generated documentation.

📂 **Documentation:** [Doxygen Notes](03-Doxygen/README.md)

---

### 📄 4. Google Docs — Collaborative Documentation

Google Docs is a cloud-based document editor that supports real-time collaboration, document formatting, and shared editing workflows.

**Key Concepts:**
- Creating and formatting documents.
- Headings, styles, and document organization.
- Tables, images, and hyperlinks.
- Sharing permissions and access control.
- Real-time collaboration.
- Comments and suggestion mode.
- Version history.
- Exporting and sharing documents.

📂 **Documentation:** [Google Docs Notes](04-Google-Docs/README.md)

---

### 🌿 5. Git — Distributed Version Control

Git is a distributed version control system used to track file changes, maintain development history, and coordinate work across software projects.

**Key Concepts:**
- Introduction to version control.
- Git architecture and workflow.
- Working directory, staging area, and repository.
- Initializing and cloning repositories.
- Tracking and committing changes.
- Viewing commit history.
- Branching and merging.
- Working with remote repositories.
- Resolving merge conflicts.
- Understanding common Git commands.

📂 **Documentation:** [Git Notes](05-Git/README.md)

📌 **Command Reference:** [Git Commands](05-Git/git-commands.md)

---

### 🌐 6. GitHub — Repository Management & Collaboration

GitHub is a cloud-based platform built around Git that enables repository hosting, collaboration, code review, and project management.

**Key Concepts:**
- Introduction to GitHub.
- Creating and managing repositories.
- Public and private repositories.
- README and Markdown documentation.
- Connecting local repositories to GitHub.
- Pushing and pulling changes.
- Branches and pull requests.
- Issues and collaboration.
- Forking and cloning repositories.
- Basic GitHub workflows.

📂 **Documentation:** [GitHub Notes](06-GitHub/README.md)

## 💻 Git Command Reference

A major component of this repository is understanding and executing Git commands through practical demonstrations.

| Command | Description |
|---------|-------------|
| `git init` | Initialize a new Git repository |
| `git clone <url>` | Clone a remote repository |
| `git status` | Display the working tree status |
| `git add <file>` | Stage a specific file |
| `git add .` | Stage changes in the current directory |
| `git commit -m "message"` | Record staged changes |
| `git log` | Display commit history |
| `git diff` | View unstaged changes |
| `git branch` | List local branches |
| `git branch <name>` | Create a new branch |
| `git switch <name>` | Switch to an existing branch |
| `git merge <branch>` | Merge a branch into the current branch |
| `git remote -v` | Display configured remotes |
| `git push` | Push commits to a remote repository |
| `git pull` | Fetch and integrate remote changes |
| `git fetch` | Download remote references and objects |

Detailed explanations, examples, and additional commands are maintained in the dedicated Git documentation.

**Explore:** [Complete Git Command Reference](05-Git/git-commands.md)
