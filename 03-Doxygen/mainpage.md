# Student Record Management — Documentation {#mainpage}

Welcome to the **Student Record Management System** documentation,
generated automatically using Doxygen.

This project demonstrates how structured documentation comments
in C++ can be transformed into professional, navigable HTML
documentation.

---

## Project Overview

The Student Record Management System is a simple C++ application
that stores student details, evaluates academic performance,
and displays the results.

The project is developed as part of the Technical Writing
Laboratory to demonstrate automated source code documentation.

## Objectives

- Understand automated documentation generation using Doxygen.
- Implement structured documentation comments in C++.
- Document classes, constructors, functions, and parameters.
- Generate HTML-based reference documentation.
- Improve software readability and maintainability.

## Features

### Student Record

Stores the following information:

- Student name
- Roll number
- Marks obtained

### Pass/Fail Evaluation

The `hasPassed()` function determines the result:

- Marks greater than or equal to 40: Pass
- Marks below 40: Fail

### Record Display

The `display()` function presents the student's details,
marks, and final result.

## Doxygen Documentation Tags

The source code demonstrates the use of:

| Tag | Purpose |
|---|---|
| `@file` | Documents the source file |
| `@brief` | Provides a short description |
| `@param` | Describes function parameters |
| `@return` | Explains return values |
| `@author` | Identifies the author |
| `@date` | Specifies the documentation date |

## How to Generate Documentation

1. Install Doxygen.
2. Open the project folder in VS Code.
3. Configure the Doxyfile.
4. Run the command:

    doxygen Doxyfile

5. Open `generated-docs/html/index.html` in a browser.
